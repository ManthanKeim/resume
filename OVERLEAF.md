# Overleaf compile fix

If you see **"fontspec requires XeTeX or LuaTeX"**:

1. Click **Menu** (top left)
2. **Settings**
3. Under **Compiler**, choose **XeLaTeX**
4. Click **Recompile**

This project includes `.overleaf/settings.json` to default to XeLaTeX when imported fresh.

Main document: **`cv.tex`**
